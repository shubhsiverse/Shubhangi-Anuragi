# Shubhangi Anuragi & Shubhsiverse — Digital Home

A bold, editorial brutalist portfolio website uniting **Content Strategy**, **Work & Organisational Psychology**, and **Creative Writing & Poetry (Shubhsiverse)**.

---

## 🚀 How to Preview and Run Locally

Because this project is built using modern semantic web standards with **zero build dependencies**, you have two super-easy ways to view it:

### Option 1: Instant Browser Preview (Zero Installation)
Simply double-click `index.html` in your Windows File Explorer! It will open directly in Google Chrome, Microsoft Edge, or any modern web browser.

### Option 2: Local Python Web Server
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then open your browser to: [http://localhost:8000](http://localhost:8000)

---

## ✏️ How to Edit Content, Poems, and Projects

All the text, case studies, thesis findings, essay links, and poems are kept in a single, organized file:
👉 **`js/content.js`**

To update anything:
1. Open `js/content.js` in your favorite editor (or Notepad).
2. Change any title, link, quote, or poem stanza.
3. Save the file and refresh your browser!

No compilation, no terminal build commands, no `node_modules` clutter.

## 🌐 Free 1-Click Deployment (Custom Domain Ready)

You can host this site for 100% free with your own custom domain (e.g. `shubhangianuragi.com` or `shubhsiverse.com`) via:

1. **GitHub Pages**:
   - Create a free GitHub repository (e.g. `shubhangi-portfolio`).
   - Push these files to GitHub.
   - In repo Settings > Pages, choose `Deploy from branch: main`. Your site will be live instantly!

2. **Netlify Drop**:
   - Go to [app.netlify.com/drop](https://app.netlify.com/drop).
   - Drag and drop this `shubhangi-portfolio` folder.
   - Your website goes live worldwide in under 10 seconds!
